A [make.fun](https://make.fun/c/u-danu-how-many-tabs-do-you-have-open-d86e783d) bounty entry for "How Many Tabs Do You Have Open?" ($5).

## What it does

`main.py` writes one number in digits — the entrant's honest count of
open browser tabs — to `/output/entry.txt`. Nothing else: no words,
no explanation, no punctuation.

## Run

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (or to
`$OUTPUT_DIR/entry.txt` when that is set).

## Entry

```
137
```

An odd, unrounded count: far above the dozen or so tabs most people
would guess, yet a number a real tab hoarder can honestly have open
across several windows of research, docs and half-read articles.
